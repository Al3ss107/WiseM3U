1 Add a list (WisePlay or M3U/M3U_PLUS)

ℹ️ Which links work and how
WiseM3U accepts both WisePlay JSON chains (short links, gists, php…) and a normal M3U/M3U8 link: the playlist's group-title values become branches/genres. It also works with Xtream Codes M3U_PLUS playlists (get.php?username=…&password=…&type=m3u_plus&output=ts) and with plain type=m3u ones (#EXTGRP directive): names and groups are read from the tvg-* attributes even when they contain commas, and any EPG declared by the source (x-tvg-url/url-tvg) is carried over to the generated playlist. The addon follows redirects, downloads nested JSON files and also imports isHost branches pointing to .m3u files. Downloads run in the background: you can keep using the page while it works.
⚠️ Copy/paste: if the URL comes from a web page or an HTML message, & may arrive as &amp;: WiseM3U fixes this on its own, both here and on the server.
⚠️ Slow panels: Xtream playlists with thousands of entries can take up to 60 s to generate; on network errors the download is retried once.
⚠️ If a list fails, the message shows the beginning of the server response: so you can tell wrong credentials from an invalid URL immediately. Note: if the source URL is served by another addon/container on the same server (e.g. another addon), that service will work on every download/refresh: this is expected, because WiseM3U has to download the source.

4 Configuration history

Every configuration change is automatically saved to the history (on the data volume, last 60 states or 30 days). Choose a state and restore only the categories you want: order, names, exclusions, merges, trash or settings. A restore creates a new state of its own, so it can always be undone. Lists added after the snapshot are not deleted. With ★ Checkpoint you save a state with a name (e.g. before a merge): checkpoints do not expire. If the configuration changes elsewhere while you are editing, saving is blocked and you are asked whether to reload the server version.

5 Live logs

Waiting for events… logs start by themselves when someone watches a channel (stream), the addon downloads a list (download) or the playlist is requested. The same lines also appear with docker logs -f wisem3u.
⚠️ Log privacy notice
Lines contain the URLs of your lists and channels, which may include usernames and passwords of IPTV services. Before sharing a screenshot or the downloaded file, redact the credentials.
